TimeDeck · 桌面任务台（便携版）
================================

怎么开始
  双击 TimeDeck.exe 就能用。不需要装 Python，不需要联网，不写注册表。
  数据存在你自己的电脑：C:\Users\<你的用户名>\.timedeck\data.json
  纯文本 JSON，可以直接打开看、复制备份、或拷到另一台机器的同一路径。

四个视图
  今日   只放没做完的事，按 已逾期 / 今天要做 / 接下来一周 / 待安排 分组
         完成后今日不再显示，去「月历」看当天做完了什么
  四象限 重要 × 紧急 2×2 格子，任务先写在这里备用，要做的点「＋ 今日」
  月历   一格一天，蓝色越深当天越满，变红表示超过超载阈值；只看不能建
  设置   默认专注时长、休息时长、超载阈值、悬浮窗与托盘开关、提醒方式

快速添加（顶部输入框，回车保存）
  明天18:00 写项目周报 #工作
  支持：今天 / 明天 / 后天 / 周五 / 9-28 / 2026-10-03 08:30 ；#标签

新建 / 修改任务
  「＋ 新建任务」或双击任意任务卡，打开表单：
    开始时间、截止时间（各自可设定或留空）、标签、一段专注时长、状态可选
    象限必选——没定象限不给保存（可以先选「暂不分派，放任务池」）
  未开始 / 进行中 / 已完成的任务都能改；表单底部可删除任务。
  任务卡右键还有：编辑 / 标记完成或重新打开 / 排到今天 / 归档 / 删除

四象限怎么用
  「紧急」这条轴由你自己判断——把任务卡拖进某个象限就定了
  拖回顶部「任务池」= 还没分象限；象限里的「＋ 今日」才排进今天要做的
  未分象限的任务照常出现在「今日」的待安排里

批量排期（四象限页「批量排期…」）
  重复规则：每天 / 每隔 N 天 / 每个工作日 / 每周固定几天
  数量：生成 N 条，或从起始日开始一直到某天为止
  右侧实时预览会落在哪几天，确认后一次生成，可回四象限再逐个拖象限

右下角悬浮倒计时
  空闲时点它      → 弹出任务列表，选一个开始专注
  计时中点它      → 暂停 / 继续
  按住拖动        → 四条边都能贴着放（留出约 4px 方便再抓回来），位置会记住
  鼠标移上去      → 展开成卡片：任务名、进度条、暂停 / 跳过 / 结束 / 主界面
  右键            → 显示主界面 / 隐藏悬浮窗 / 取消置顶 / 退出
  主界面右上角的「悬浮窗 · 开/关」按钮控制它显示与否

专注时长（按任务单独设）
  任务行上的「25 分 ▾」→ 15 / 25 / 45 / 60 / 自定义，只对这一个任务生效并记住
  没单独设过的任务用默认值：左下角 设置 → 默认专注时长

关于「关闭」和托盘
  点窗口右上角的关闭 = 隐藏到托盘，计时继续跑，右下角悬浮窗照常倒数
  真正退出：托盘图标右键 → 退出 TimeDeck（或悬浮窗右键 → 退出程序）
  本程序不设置开机自启；想开机就跑，把下面的快捷方式拷到
  C:\Users\<你的用户名>\AppData\Roaming\Microsoft\Windows\Start Menu\Programs\Startup

分享给别人
  把整个 TimeDeck 文件夹复制给对方（U 盘 / 网盘 / 压缩包都行），对方双击 TimeDeck.exe 即可。
  想连任务一起给：设置 → 导出 data.json 副本 → 对方放到自己的 .timedeck 目录后再启动。

出问题
  如果哪里点了没反应或闪退，打开 C:\Users\<你的用户名>\.timedeck\error.log
  把最后那一段报错复制出来就能定位原因（报错里可能带任务标题，发给别人前自己先看一眼）。
  数据本身有滚动备份 data.json.bak0 ~ bak9，写坏了可以拿最近一份改回来。

卸载
  删除 TimeDeck 文件夹 + C:\Users\<你的用户名>\.timedeck 就干净了。
